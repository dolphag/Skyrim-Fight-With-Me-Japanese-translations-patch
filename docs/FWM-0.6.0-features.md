## 何をする MOD か
- 従者ごとに、**役割(role)・注目対象(focus)・位置取り(position)**を決め、戦闘の AI(ゲーム本来のもの)がそれを実行する。誰と戦い、どこに立つかを決める MOD で、攻撃の中身(アビリティ・特性・レベル)は Path of the Companions(Paths)の担当。
- Numpad 7(コントローラは LB + 十字キー下)でバトルプランを開くと、世界がほぼ止まり、その場で指示できる。SKSE Menu Framework 3 が必要(無くても保存済みの指示と INI は効く)。

## 用語(訳との対応)
| 原作の語 | 意味 | 現行の訳 |
|---|---|---|
| role | 立ち位置・狙う相手・動き方のまとまり。武器や攻撃方法は決めない | 役割 |
| Fighter / Tank / Healer / Bruiser / Archer / Mage / Skald | 7 役割(Skald は 0.6.0 で追加。Paths 1.2・リュート・10 ポイントの解放が必要) | ファイター/タンク/ヒーラー/ブルーザー/アーチャー/メイジ/スカルド |
| focus | 誰を狙うか(自分で選ぶ・あなたの標的・あなたやパーティを攻撃する相手・術者と弓兵・最強・最弱・印を付けた 1 体) | 注目対象 |
| position | 立つ場所(自由・あなたを守る・後方待機・前線・あなたと一緒) | 位置取り |
| Hold back | 近づいてきた敵とだけ戦う。パーティ命令の「後方待機」と、位置の 1 つ | 後方待機 |
| Role strength | 役割と位置が従者をどれだけ動かすか。0 なら狙う相手だけ変わる | 役割の強さ |
| Auto battle | 初期はオフ。オンだと、2500 ユニット以内で敵を見た従者が戦闘を始め、全員が武器を構える(隠密中は除く) | オートバトル |
| Loadout / pool | 従者の装備の候補。選ぶと戦闘 AI がその中から使う(所持品は減らない)。メイジとヒーラーは両手ごとの魔法の候補も持つ | 候補(「プール」は使わない) |
| Role weapons | 各役割を専用の武器に縛る設定(初期はオン)。オフなら持っている武器・盾を何でも使える。スカルドのリュートは変わらない | 役割ごとの武器 |
| Ljodh | スカルドの 4 つの歌(アビリティ)。中断できる | リョード |

## 版 0.6.0 で変わったこと(原作 README の記載)
- Skald、役割ごとの武器の設定、テーマ付きポインタ(コントローラ操作中は隠れる)、テーマの変更が Walk With Me・Paths と共有される(3 つとも更新した場合)。
- Auto battle オフ(初期)では、敵が見えても武器は出さない(以前は出てしまう不具合があった)。
- 従者のレベル・経験値の表示が Paths のパネルと一致した、戦闘 AI への「素手を使ってよいか」の反映、文字化けの修正。
- FWM 0.6.0 は Paths 1.2 とだけつながる(古い版とは連携しない)。3 つの DLL(FWM・Paths・Walk With Me)は一緒に更新する。
