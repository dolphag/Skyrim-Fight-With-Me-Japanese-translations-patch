# 翻訳方針(Fight With Me / Path of the Companions / Walk With Me 共通)

作成: 2026-10-27(下書き)。3 つの日本語化パッチの訳を揃えるための方針。人間の翻訳者にも LLM にも、これだけ読めば同じ品質の訳が出せることを目指す。

- 対象 MOD と方式
  - Fight With Me(FWM)・Path of the Companions(Paths): 原作が外部ファイルに分けたメッセージの日本語版(`*_JAPANESE.txt`)を置く。表は各リポジトリの `translations_en_ja.csv`(列 `en,ja`)。
  - Walk With Me(WWM): 現状は DLL パッチ。表は `translations_en_ja.csv`(列 `English,Japanese`)。外部ファイル化されたら FWM と同じ方式に移る見込み(未確認)。
- 各項目の状態を 3 つに分ける。
  - **【方針】**: 決定済み。守る。
  - **【現状】**: 2026-10-27 時点の CSV を集計した実態(数字は当日の実測)。方針ではない。
  - **【要決定】**: まだ決まっていない。決まるまで、既存の訳に合わせる。

## 1. 優先順位
**【要決定】D0** 次の順は、今の訳の実態から私(Claude)が起こした案で、まだ了承を得ていない。
1. **意味が正しい**(数値・条件・対象を落とさない)。
2. **画面に収まる**(原文の約半分の長さが実績。窮屈な場所は短くする)。
3. **用語が揃っている**(`docs/GLOSSARY.md`)。
4. **自然な日本語**。

## 2. 文体
【現状】FWM 822 項目の語尾: 句点なし 462(ラベル・見出し)/「。」止め 211/です・ます 149。Paths は 1099 項目で同じ比率、WWM は 320 項目で です・ます が比較的多い(83)。
- ラベル・見出し・ボタン: 体言止めで句点なし(例: 習熟済み、やり直す、従者を選ぶ)。
- **【方針】** 数値は半角、全角数字は使わない(全角数字 0 件)。
- **【現状】** 効果の説明(アビリティの説明)は「〜する。」の常体が多い。設定画面の説明や状況メッセージは「〜します。」「〜ません。」が多い。ただし例外が多く、機械的な規則にはなっていない。
- **【要決定】D1** 文体の線引き。案: 「利用者に語りかける文(設定の説明、操作案内、状況メッセージ)= です・ます」「ゲーム内の効果・条件の記述とラベル = 常体・体言止め」。既存の例外を洗い出して直すかは別途。
- 二人称: 「あなた」が使われている例がある(「あなたの前で戦線を守り」)。省略できる場合の扱いは未整理(**【要決定】D1c**)。

## 3. 用語
- 正本は `docs/GLOSSARY.md`。変更はユーザー(パッチ作者)の了承が要る。
- 公式日本語訳(バニラの Skyrim 日本語版)がある語は、それに合わせる(時間減速、治癒の手 など)。入手元: WWM の `CLAUDE.md` は「Fandom wiki の一覧(ファンによる抽出であり公式サイトではない)」と記している。
- 公式訳が無い語(MOD 独自の名前)の付け方:
  - **【現状】** 意訳(刃の道、戦意喪失、最後の砦、癒しの円)と音訳(ケイオスダウン、ウォークライ、マグナス)が両方ある。
  - **【要決定】D2** 基準。案: 意味が伝わる短い日本語があれば意訳、ゲーム内の固有名として定着している外来語(ウォークライなど)は音訳。迷う語は GLOSSARY に「暫定」で載せる。
- **【現状】** `docs/GLOSSARY.md` の「0.5.0 / Paths 1.0 で追加」の語は「暫定。実機確認前」。確定の手順は決まっていない(**【要決定】D1b**)。
- 固有名詞(MOD 名・ボタン名・キー名): 原作の英語のまま。Esc、Tab、LB + Y、Walk With Me など(FWM で 20 項目が英語のまま)。

## 4. 書式欄・記号
- **【方針】** `{}` `{0}` `{:.0f}` `%.0f` `%d` などの書式欄は、種類と数を英語と一致させる。順序を入れ替える必要があるときだけ番号付き(`{1}{0}`)にする。FWM/Paths は `lang_build.py` が機械検査する。WWM は `verify.py`。**検査が通らない訳は出さない**(表示が壊れうる唯一の項目)。
- `\n` は実際の改行として保持する(CSV では実改行)。
- **【方針】** 矢印 `→` は使わない(HUD のフォントに無い。0.3.0 での観察。0.5.0 は未確認)。`：` や `、` で代用する。
- 単位: 数字の直後に付ける(10m、5本、{:.0f}%)。**【要決定】D3** WWM は `%.0f ユニット`(空白あり)、FWM/Paths は `%.0fユニット`(空白なし)。揃えるなら空白なし。
- 括弧: `「 」` は、シャウト名・ボタン名などの引用に使われている(FWM 13 項目)。

## 5. 長さと折り返し
- **【方針】** 折り返しは ASCII の半角スペースでしか起きない。長文には文節の区切りに半角スペースを入れる(FWM/Paths は `lang_build.py` が日本語形態素解析で自動で入れる。CSV の `ja` には入れない)。
- 表示倍率・位置は、FWM/Paths では訳から調整できない。WWM は DLL の定数で調整できる(日本語は英字より小さく見える)。
- 窮屈な場所は訳を短くする(これは既存のルール)。体言止めにするのはその手段の一つ。

## 6. 使える文字
- FWM/Paths: `tools/jp_kanji.txt` の範囲内。範囲外の漢字はひらがなにする(`lang_build.py` が失敗で知らせる)。ゲーム由来の文字列は変えられないので、利用者には EnableChinese を勧めている。
- WWM: 置き換えフォント(Noto Sans JP のサブセット)に、訳に使った漢字を取り込む。範囲の制限は無い。**【要決定】D4** 外部ファイル化後に FWM と同じ方式になるなら、この制限が変わる。

## 7. 訳さないもの
- ホイールのモード名・タイル名(WWM: Natural / Lead など)、コード内に埋め込まれて安全に置換できない文字列、ログ。
- 原作が一覧を通していない文字列(FWM のパーティ設定ページのドロップダウン)。原作者への報告案は `docs/upstream-report-draft.md`。

## 8. LLM に下訳させるとき
入力: ①この文書 ②`docs/GLOSSARY.md` ③既存の CSV(訳済みの項目。**同じ語は同じ訳にする**ため必ず渡す) ④翻訳する項目(`lang_build.py` の「未訳」)。
- 訳済みの項目は変えない。新しい項目だけ訳す。
- 書式欄・`\n` はそのまま写す。数値は変えない。
- 用語集に無い固有名は、勝手に確定せず「暫定」と注記して返させる。
- 返すもの: CSV の行 + 迷った箇所の一覧(なぜ迷ったか)。
- 出力は必ず検査(FWM/Paths は `lang_build.py`、WWM は `verify.py`)を通す。通らなければ人間が直す。

## 9. 確認の水準
- **【方針】** 利用者に出す版は、実機で確認する(スクリーンショットと所見)。
- 下訳のまま出す場合(将来の想定)は、そう明記する。読者に「未確認の機械翻訳」と分かるように。修正は PR か Issue で受ける。

## 10. 3 リポジトリ間の差異(2026-10-27 時点)
- FWM と Paths の CSV: 共通 821 項目、訳の違い 0。Paths の CSV は FWM の上位集合(1099 項目 ⊃ 822 項目)。二重に保守しており、ずれる余地がある。**【要決定】D5** 共通部分をどちらかに寄せるか。
- FWM と WWM の共通項目 14 のうち、訳が違うもの 5: COMPANIONS(従者 / 従者一覧)、Spread out(分散 / 広げる)、Troubleshooting(問題の調査 / トラブルシューティング)、`%.0f units`(空白の有無)、Setting(設定 / 設定項目)。**【要決定】D6** どちらに揃えるか。
- 列名: FWM/Paths は `en,ja`、WWM は `English,Japanese`。
- 用語の使用状況(WWM): 隊列 12 件(FWM 1 件)、仲間 2 件(FWM 0 件。「誰が仲間にした従者でも」の動詞用法)。
