English

An unofficial Japanese translation of [url=https://www.nexusmods.com/skyrimspecialedition/mods/195610]Paths[/url] by hashhbbrown (tree screens, all 88 nodes, ranks, bonuses, guide, settings, notices). 

[b]Note: [/b]
Paths' screen text is not inside Paths but inside Fight With Me's FightWithMe.dll, so this patch replaces that DLL (and translates Fight With Me's own screens too). 

[b]Install order: [/b]
Fight With Me -> Paths -> this patch (last). Recommended: EnableChinese = true under [Fonts] in SKSEMenuFramework.ini (SMF v3.18+). 
The DLL is identical to the one in the Fight With Me Japanese patch ([url=https://www.nexusmods.com/skyrimspecialedition/mods/194874]https://www.nexusmods.com/skyrimspecialedition/mods/194874[/url]); install only one of them. 

Source scripts only on GitHub: [url=https://github.com/dolphag/Skyrim-Fight-With-Me-Japanese-translations-patch]https://github.com/dolphag/Skyrim-Fight-With-Me-Japanese-translations-patch[/url] .
