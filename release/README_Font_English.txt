Fight With Me - Japanese UI Font 0.5.0-1 (Japanese font for Fight With Me)
=====================================================================
A Japanese-capable font for the Japanese translation patch. **Without it Japanese shows as "?".**
The original draws its screens with theme fonts (Lora-SemiBold / Spectral-SemiBold / BarlowSemiCondensed-SemiBold) that have no Japanese glyphs. This file puts a font with Japanese glyphs under the same names.

Install
- Install Fight With Me, then the Japanese Translations Patch, then this file.
- Mod order: original -> patch -> this file, so it overwrites the original's fonts of the same names (Fight With Me and Paths ship identical fonts; put this after both).
- Files placed: SKSE/Plugins/Fonts/Lora-SemiBold.ttf, Spectral-SemiBold.ttf, BarlowSemiCondensed-SemiBold.ttf (identical content).
- Latin letters will look different (the same gothic face as the Japanese). Disable it to get the original fonts back.
- The Path of the Companions Japanese patch page has the same font; either one is enough (same file names).
- You can use your own font instead: copy any Japanese-capable TTF under the three names above.
