Fight With Me - Japanese UI Font 0.5.0-1 (Fight With Me 用 日本語フォント)
=====================================================================
日本語化パッチ用の、日本語対応フォントです。**これを入れないと、画面の日本語が「?」になります。**
原作の画面は、日本語の字形を持たないテーマ用フォント(Lora-SemiBold / Spectral-SemiBold / BarlowSemiCondensed-SemiBold)で描かれます。
このファイルは、同じ名前で日本語の字形を持つフォントを置いて、表示できるようにします。

■ 導入
- Fight With Me 本体と、日本語化パッチ(Fight With Me - Japanese Translations Patch)を入れたあとに、このファイルを入れてください。
- MOD の優先順位は、原作 → 日本語化パッチ → このファイルの順にして、原作の同名ファイルを上書きします(Fight With Me と Paths は同じ名前のフォントを持つので、両方より後にします)。
- 置かれるファイル: SKSE/Plugins/Fonts/Lora-SemiBold.ttf, Spectral-SemiBold.ttf, BarlowSemiCondensed-SemiBold.ttf(中身は同じです)。
- 英字の見た目が、原作のフォントから変わります(日本語と同じゴシック体になります)。
- 無効にすれば、元のフォントに戻ります。
- Path of the Companions の日本語化パッチのページにも、同じ内容のフォントがあります。どちらか一方で構いません(同名のファイルです)。
- 自分のフォントを使うこともできます: 日本語対応の TTF を、上の3つの名前でコピーしてください。
