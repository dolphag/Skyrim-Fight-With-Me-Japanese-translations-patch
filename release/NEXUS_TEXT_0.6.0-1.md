## ページの説明(要点。bbcode に整形して使う)
1. 原作へのリンクとクレジット(hashhbbrown / fatalCMD)。非公式の翻訳で、原作者に問い合わせないこと。
2. **導入に必要なもの**: Fight With Me 0.6.0、SKSE Menu Framework 3 の日本語設定、SKSE Menu Framework の日本語設定。旧版(0.3.0-2 以前の DLL 版)は外す。
3. **日本語にならないとき**: 英語設定(ENGLISH)でもファイルを置くだけで日本語になる。それ以外の言語名のときは `sLanguage = JAPANESE`(効くのはその MOD の画面だけ。SMF 全体・ゲーム本体には影響しない)(英語版ゲームの場合は `FightWithMe_user.ini`)。ログの `[Text] JAPANESE: N lines`。
4. **日本語にならないもの**: パーティ設定ページの役割(スカルド含む)・注目対象・位置取りのドロップダウン(原作側の漏れ)、バトルプラン設定「問題の調査」の説明の一部、テーマ名(原文のまま)、ゲーム由来の文字列。
5. Path of the Companions を使う人には、Paths 用の日本語化パッチ(別ページ)を案内する。
6. スクリーンショット(バトルプラン、設定)。AI 利用の開示。他サイトへの転載はご遠慮ください。
7. 対応版: Fight With Me 0.6.0。原作の更新時はパッチを外さなくてよいが、新しい文言は英語のまま。
8. GitHub(ソースのみ): https://github.com/dolphag/Skyrim-Fight-With-Me-Japanese-translations-patch
